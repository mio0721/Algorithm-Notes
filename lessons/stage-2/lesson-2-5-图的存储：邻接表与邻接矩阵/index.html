阶段 2 · 第 2.5 节

图的存储：邻接表与邻接矩阵

阶段 2 · 已接触入门
这一节要解决什么？

程序需要知道每个路口能直接通向哪些路口。邻接表按路口列出邻居，邻接矩阵用表格记录两点之间是否有边。

一、先理解做法

例如无向边 0—1、0—2：邻接表中 0 有 [1,2]；矩阵中 A[0][1] 和 A[1][0] 都为 1。存有向边时只填写对应方向。

二、逐步观察

这是一个固定例子。先猜测下一步，再点击按钮；高亮表示当前关注的元素或状态。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

vector<vector<int>> graph(3);
auto addEdge = [&](int a, int b) {
    graph[a].push_back(b);
    graph[b].push_back(a); // 无向边需要反向记录
};
addEdge(0, 1);
addEdge(0, 2);
for (int neighbor : graph[0]) cout << neighbor << ' ';

四、复杂度与适用条件

邻接表空间 O(V+E)，无向边通常存两次；邻接矩阵空间 O(V²)，可 O(1) 查询是否存在某条边。

五、独立练习

自己建立 4 个节点和无向边 0—1、1—2、1—3，写出每个节点的邻接表。

查看提示与易错点

vector<vector<int>> 外层下标是节点编号，内层 vector 保存这个节点的邻居。

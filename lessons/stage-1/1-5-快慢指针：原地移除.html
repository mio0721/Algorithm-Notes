阶段 1 · 第 1.5 节

快慢指针：原地移除

LeetCode 27
这一节要解决什么？

把列表中等于指定值的记录移出有效区间，像把需要保留的物品逐件放到队首。

一、先理解做法

fast 遍历每个元素；slow 表示下一个可写入的位置。只有遇到需要保留的值才写入并递增 slow。

二、逐步观察

可修改数组与目标；逐步观察指针、当前比较位置和有效区间。浅色方格表示当前区间或已保留前缀，淡化的方格表示区间之外。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

int removeElement(vector<int>& nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < (int)nums.size(); ++fast) {
        if (nums[fast] != val) {
            nums[slow] = nums[fast];
            ++slow;
        }
    }
    return slow;
}

四、复杂度与适用条件

时间 O(n)，额外空间 O(1)。此实现保留剩余元素的相对顺序，返回前缀长度。

五、独立练习

对 [0,1,2,2,3,0,4,2] 移除 2，手算有效长度及最终前缀。

查看提示与易错点

不要在每次循环里把 slow 重置为 0；返回的是保留下来的元素数。

六、完成前自查

  1. 能不看代码描述变量的含义和每一步变化吗？
  2. 能解释循环或递归何时结束，以及空输入、边界情况如何处理吗？
  3. 能独立复写，并解释时间与额外空间复杂度吗？

本题题目

27. 移除元素

给定整数数组 nums 和值 val，原地移除所有等于 val 的元素，返回剩余元素个数 k；结果写在前 k 个位置。

输入 / 输出示例

输入nums = [3,2,2,3], val = 3输出k = 2，前 2 项为 [2,2]

条件与边界

本课实现保持剩余元素相对顺序；原题允许改变顺序。 0 ≤ 数组长度 ≤ 100；元素在 [0,50] 内，val 在 [0,100] 内。

演示区为方便观察最多接受 20 个数，数值绝对值不超过 1000000；实际题目以这里的限制为准。

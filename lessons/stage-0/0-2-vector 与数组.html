vector 与数组

阶段 0 · 基础备查
这一节要解决什么？

vector 可以理解成可以自动管理大小的连续容器：地图里的一列节点编号可以逐个加入。

一、先理解做法

下标从 0 开始，size() 给出元素个数，最后一个有效下标是 size()-1。push_back 在末尾追加；传引用可以避免不必要的整份复制。

二、逐步观察

这是一个固定例子。先猜测下一步，再点击按钮；高亮表示当前关注的元素或状态。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

vector<int> makeValues() {
    vector<int> nums;
    nums.push_back(4);
    nums.push_back(7);
    return nums;
}

四、复杂度与适用条件

下标访问 O(1)；末尾 push_back 均摊 O(1)，偶发扩容需要移动元素。越界访问 nums[i] 的行为未定义。

五、独立练习

创建一个 vector，依次加入 3、6、9，用循环打印下标和对应元素。

查看提示与易错点

循环条件用 i < nums.size()；空 vector 没有最后一个元素。

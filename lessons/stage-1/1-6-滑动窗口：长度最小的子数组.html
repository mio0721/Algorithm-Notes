阶段 1 · 第 1.6 节

滑动窗口：长度最小的子数组

LeetCode 209
这一节要解决什么？

机器人在一段连续时间内累计行驶距离至少为目标值，想找满足条件的最短连续时间段。

一、先理解做法

right 向右扩展窗口并累加；只要窗口和达到目标，就记录长度并不断移动 left 缩小窗口。题目要求所有元素均为正数，这保证缩小窗口会减小窗口和。

二、逐步观察

可修改数组与目标；逐步观察指针、当前比较位置和有效区间。浅色方格表示当前区间或已保留前缀，淡化的方格表示区间之外。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

int minSubArrayLen(int target, vector<int>& nums) {
    int left = 0, sum = 0, best = (int)nums.size() + 1;
    for (int right = 0; right < (int)nums.size(); ++right) {
        sum += nums[right];
        while (sum >= target) {
            best = min(best, right - left + 1);
            sum -= nums[left];
            ++left;
        }
    }
    return best == (int)nums.size() + 1 ? 0 : best;
}

四、复杂度与适用条件

时间 O(n)，额外空间 O(1)，每个指针最多前进 n 次。若允许负数，不能直接沿用本算法。

五、独立练习

给定 target=11、数组 [1,2,3,4,5]，先手算最短窗口，再独立实现。

查看提示与易错点

内层是 while：同一个 right 下可能需要连续缩小多次；注意找不到时返回 0。

六、完成前自查

  1. 能不看代码描述变量的含义和每一步变化吗？
  2. 能解释循环或递归何时结束，以及空输入、边界情况如何处理吗？
  3. 能独立复写，并解释时间与额外空间复杂度吗？

本题题目

209. 长度最小的子数组

给定由正整数组成的数组和正整数 target，找到和大于或等于 target 的最短连续子数组，返回其长度；不存在则返回 0。

输入 / 输出示例

输入target = 7, nums = [2,3,1,2,4,3]输出2，对应 [4,3]

条件与边界

原题数组非空、元素和 target 均为正整数；空数组在此作为扩展边界练习。 1 ≤ target ≤ 10⁹；1 ≤ 数组长度 ≤ 10⁵；元素在 [1,10⁴] 内。

演示区为方便观察最多接受 20 个数，数值绝对值不超过 1000000；实际题目以这里的限制为准。

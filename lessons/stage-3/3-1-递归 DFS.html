阶段 3 · 第 3.1 节

递归 DFS

深度优先搜索
这一节要解决什么？

在路网中先沿一条路走到不能再走，再返回岔路。

一、先理解做法

进入节点先标记，再递归访问每个未访问的邻居；需要覆盖不连通图时，从每个未访问节点重新启动。

二、逐步观察

可选择不同预设或编辑图与地图，应用后重新计算搜索过程。修改地图会回到第一步；使用下方按钮逐步观察或自动播放。完整代码提供固定示例，可对照修改数据。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

#include <iostream>
#include <vector>
#include <string>
#include <queue>
#include <stack>
#include <unordered_map>
#include <functional>
#include <algorithm>
using namespace std;

int main() {
    vector<vector<int>> g = {
        {1, 2},
        {0, 3, 4},
        {0, 5, 6},
        {1, 7},
        {1, 8, 5},
        {2, 4},
        {2, 9},
        {3},
        {4, 9},
        {6, 8}
    };
    vector<bool> seen(g.size(), false);

    function<void(int)> dfs = [&](int u) {
        seen[u] = true;
        cout << char('A' + u) << " ";

        for (int v : g[u]) {
            if (!seen[v]) {
                dfs(v);
            }
        }
    };

    dfs(0);
    cout << endl;
    return 0;
}

四、复杂度与适用条件

邻接表遍历时间 O(V+E)，visited 和递归栈最坏各 O(V)。递归深度过大可能溢出。

五、独立练习

写出从 A 出发的访问顺序并比较邻居顺序改变后的结果。

查看提示与易错点

DFS 的访问顺序取决于邻接表顺序。

vector 与数组

阶段 0 · 基础备查

一、简单例子

机器人连续记录多个传感器读数，需要按顺序存放、按位置取出，还可能在末尾继续追加。数组与vector就是保存这串数据的工具。

先看一个小例子

读数是 [10,20,30]：第一个位置放10，编号从0开始；追加40后变成 [10,20,30,40]。原来三个读数的相对顺序没有变。

二、解释与思考

数组把一串数据放在连续的位置上，因此知道下标，就能直接找到对应元素，不必从头寻找。vector 可以看作能自动扩容的数组：空间不够时会申请一块更大的存储，再把原来的元素搬过去。它适合按位置读取和在末尾追加；在中间插入或删除时，后面的元素通常需要移动。

  1. 把数据按顺序放进容器。
  2. 用下标定位，用循环逐个查看。
  3. 追加或删除后重新确认长度和有效下标。

四、深入理解

vector 可以理解成可以自动管理大小的连续容器：地图里的一列节点编号可以逐个加入。

把刚才的动作说准确

下标从 0 开始，size() 给出元素个数，最后一个有效下标是 size()-1。push_back 在末尾追加；传引用可以避免不必要的整份复制。

边界与扩容

空容器没有第一个或最后一个元素。C++ 的 size() 是无符号类型，空数组时直接计算 size()-1 有下溢风险；需要先判断为空。末尾扩容可能使原有迭代器、指针和引用失效。

Python 的 list 可通过 append 追加，语法相似但不是 C++ vector：负下标有效，内部存储与元素类型规则也不同。

五、复杂度与易错点

需要多少工作与存储？

下标访问 $O(1)$；末尾 push_back 均摊 $O(1)$，偶发扩容需要移动元素。越界访问 nums[i] 的行为未定义。

容易错在哪里具体反例怎样改
把长度当最后下标长度3时访问nums[3]已经越界有效下标是0、1、2。
扩容后继续使用旧引用push_back可能重新分配底层内存会变更容量的操作后重新取得引用或迭代器。
再检查一个容易忽视的条件

循环条件用 i < nums.size()；空 vector 没有最后一个元素。

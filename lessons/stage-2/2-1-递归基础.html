阶段 2 · 第 2.1 节

递归基础

阶段 2
这一节要解决什么？

想沿一条走廊数房间：先走进一个房间，再把剩下的房间交给同样的规则处理，直到没有房间。递归就是函数在合适的条件下调用自身。

一、先理解做法

先确定函数负责什么，再写终止条件和缩小问题的递归调用。以 sum(n) 为例，sum(n)=n+sum(n-1)，当 n=0 时返回 0；本例假设 n 为非负整数。

把递归拆成三个问题

先说清函数含义：sum(n) 返回 1 到 n 的和；再定义最小问题 sum(0)=0；最后让 sum(n) 依赖更小的 sum(n−1)。例如 sum(3) 等待 sum(2)，直到基例，再逐层返回。

每次调用要接近基例；传入负数并不满足本例前提。递归深度太大可能造成栈溢出。

二、逐步观察

这是一个固定例子。先猜测下一步，再点击按钮；高亮表示当前关注的元素或状态。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

int sum(int n) {
    if (n == 0) return 0;
    return n + sum(n - 1);
}

四、复杂度与适用条件

时间 O(n)，递归调用栈空间 O(n)。递归层数过大时可能导致栈溢出。

五、独立练习

写一个递归函数计算 1 到 n 的乘积（n 为非负整数），规定 0 的结果为 1。

查看提示与易错点

先写 n=0 的结果；每次让参数更靠近 0。大 n 时整数乘积可能溢出。

C++ 完整实现

// visited 访问标记
// 学习重点：准备一份访问标记。
// 发现一个新节点时，先标记，再加入待处理集合。
// 只继续处理尚未标记的邻居。
// C++17；直接编译运行 main() 中的示例。
#include <iostream>  // 控制台输入与输出
#include <vector>  // 动态数组、邻接表或状态表
#include <queue>  // 先进先出队列或优先队列

using namespace std;

// 程序入口：准备示例数据，调用算法，并输出结果供手算核对。
int main() {
    vector<vector<int>> graph{{1,2},{0,2},{0,1}};
    // 访问标记初始为空或全为假，表示还没有发现节点。
    vector<bool> visited(graph.size(), false);
    queue<int> pending;
    // 发现时先标记，避免多个邻居把同一个节点重复入队。
    int start=0; visited[start]=true; pending.push(start);
    // 反复取出一个待处理状态；集合耗尽时，本轮搜索结束。
    while (!pending.empty()) {
        // 读取先进先出的队首，保持发现的层次顺序。
        int u=pending.front(); pending.pop();
        // 输出计算结果，便于与课程例子或自行推演的答案核对。
        cout << "访问 " << char('A'+u) << "\n";
        for (int v : graph[u]) if (!visited[v]) {
            // 发现时先标记，避免多个邻居把同一个节点重复入队。
            visited[v]=true; pending.push(v);
        }
    }
}

# visited 访问标记
# Python 3；直接运行文件，修改示例数据可继续练习。
# 准备一份访问标记。

from collections import deque
graph = [[1, 2], [0, 2], [0, 1]]
visited = [False] * len(graph)
pending = deque([0])
# 发现时先标记，避免多个邻居把同一个节点重复入队。
visited[0] = True
# 反复取出一个待处理状态；集合耗尽时，本轮搜索结束。
while pending:
    # 读取先进先出的队首，保持发现的层次顺序。
    node = pending.popleft()
    # 输出计算结果，便于与课程例子或自行推演的答案核对。
    print('访问', chr(ord('A') + node))
    for neighbor in graph[node]:
        if not visited[neighbor]:
            # 发现时先标记，避免多个邻居把同一个节点重复入队。
            visited[neighbor] = True
            pending.append(neighbor)

写代码时最容易错的地方

出队才标记导致重复入队

A 的邻居 B、C 都连接 D。

容易写错
q.push(v); // 出队时才 seen[v]=true
修改后
if (!seen[v]) { seen[v]=true; q.push(v); }

B、C 都可能在 D 出队前把 D 加入队列。

枚举路径时永久标记

图有 A→B→D 与 A→C→D 两条路径。

容易写错
seen[v] = true;
dfs(v); // 永不撤销
修改后
onPath[v] = true;
dfs(v);
onPath[v] = false;

枚举简单路径需要撤销当前路径标记，否则另一分支漏掉 D。

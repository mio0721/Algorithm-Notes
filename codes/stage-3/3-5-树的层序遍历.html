树的层序遍历

C++ 完整实现

// 树的层序遍历
// 学习重点：当前队列里保存本层节点。
// 先记住队列长度，恰好取出这么多个节点。
// 把孩子加入队尾，留给下一轮。
// C++17；直接编译运行 main() 中的示例。
#include <iostream>  // 控制台输入与输出
#include <vector>  // 动态数组、邻接表或状态表
#include <queue>  // 先进先出队列或优先队列

using namespace std;

// 程序入口：准备示例数据，调用算法，并输出结果供手算核对。
int main() {
    vector<vector<int>> children = {
        {1, 2},
        {3, 4},
        {5, 6},
        {7},
        {8},
        {},
        {9},
        {},
        {},
        {}
    };
    queue<int> pending;
    pending.push(0);

    // 反复取出一个待处理状态；集合耗尽时，本轮搜索结束。
    while (!pending.empty()) {

        int count = static_cast<int>(pending.size());
        for (int i = 0; i < count; ++i) {
            // 读取先进先出的队首，保持发现的层次顺序。
            int u = pending.front();
            pending.pop();
            // 输出计算结果，便于与课程例子或自行推演的答案核对。
            cout << u + 1 << " ";

            for (int v : children[u]) {
                pending.push(v);
            }
        }
        // 输出计算结果，便于与课程例子或自行推演的答案核对。
        cout << endl;
    }
    return 0;
}

# 树的层序遍历
# Python 3；直接运行文件，修改示例数据可继续练习。
# 当前队列里保存本层节点。

from collections import deque
children = [[1, 2], [3, 4], [5, 6], [7], [8], [], [9], [], [], []]
queue = deque([0])
# 反复取出一个待处理状态；集合耗尽时，本轮搜索结束。
while queue:
    level = []
    # 每层先保存队列当前长度，只处理这一层原有节点。
    for _ in range(len(queue)):
        # 读取先进先出的队首，保持发现的层次顺序。
        node = queue.popleft()
        level.append(node + 1)
        queue.extend(children[node])
    # 输出计算结果，便于与课程例子或自行推演的答案核对。
    print(level)

写代码时最容易错的地方

循环边界使用变化的队列长度

本层队列 [B,C]，B 的孩子为 D、E，C 的孩子为 F、G。

容易写错
for (int i=0; i<q.size(); ++i) { /* 出队并加入孩子 */ }
修改后
int width=q.size();
for (int i=0; i<width; ++i) { /* 处理 */ }

q.size() 随出队和入队变化，可能把下一层混进本层。

各层复用同一列表引用

Python 保存第 1 层 [A]，继续填充同一列表。

容易写错
result.append(level)
level.clear()
修改后
result.append(level.copy())
level.clear()

保存引用后清空原列表会清空已保存层。

阶段 3 · 第 3.3 课

DFS 与回溯

路径枚举

一、简单例子

有时不是问能否到达，而是要列出所有不重复绕圈的路线。走完一种选择后，要撤销它，才能试另一种。

先看一个小例子

A→B→D和A→C→D都是有效路线。走完第一条后，要把B和D从当前路径撤销，再尝试经C的分支。

二、解释与思考

DFS 与回溯可以理解为“试一个选择，探索它带来的结果，再恢复现场”。例如枚举路线时，把新节点加入当前路径，递归探索后再移除它，并撤销相应的路径标记。这样下一个分支才能从相同的起始状态继续尝试，避免前一个分支留下的内容污染后面的答案。

  1. 进入节点时把它加入当前路线。
  2. 到达目标就保存路线副本。
  3. 返回时撤销本层路线与路径标记。
操作前先猜一猜

找到经B到D的路线后，能不能永久禁止其他分支再次使用D？

三、操作示意，观察过程

可选择不同预设或编辑图与地图，应用后重新计算搜索过程。修改地图会回到第一步；使用下方按钮逐步观察或自动播放。完整代码提供固定示例，可对照修改数据。

四、深入理解

探索一条路线后撤销选择，继续尝试其他路线。

把刚才的动作说准确

将当前节点放进路径并标记；搜索相邻节点；返回后弹出并撤销路径标记，以允许其他路径使用该节点。

五、复杂度与易错点

需要多少工作与存储？

枚举所有简单路径在最坏情况下可呈指数或阶乘级增长，取决于图结构；空间包括当前路径与标记。

容易错在哪里具体反例怎样改
永久visited漏掉其他路径A→C→D也需要访问D使用当前路径内的标记，返回时撤销。
把同一列表引用保存多次继续回溯后已保存的答案也变化保存路径副本。
再检查一个容易忽视的条件

枚举简单路径用路径内标记；普通连通性遍历的全局标记通常不撤销。

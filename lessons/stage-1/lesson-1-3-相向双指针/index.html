阶段 1 · 第 1.3 节

相向双指针

LeetCode 167 · 已练习
这一节要解决什么？

两个车站距离已经从小到大排列，想找到距离之和等于目标的两个站点。

一、先理解做法

从两端开始：和太小就移动左指针，试着增大和；和太大就移动右指针，试着减小和。题目返回从 1 开始的下标。

二、逐步观察

可修改数组与目标；逐步观察指针、当前比较位置和有效区间。浅色方格表示当前区间或已保留前缀，淡化的方格表示区间之外。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

vector<int> twoSum(vector<int>& numbers, int target) {
    int left = 0, right = (int)numbers.size() - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) return {left + 1, right + 1};
        if (sum < target) ++left;
        else --right;
    }
    return {}; // 通用写法；原题保证有解
}

四、复杂度与适用条件

时间 O(n)，额外空间 O(1)；依赖输入升序。

五、独立练习

在 [1,2,4,8,12] 中找和为 10 的两个数，记录指针每次变化。

查看提示与易错点

和小于目标时，只移动右指针会让和更小；注意原题的返回下标从 1 开始。

六、完成前自查

  1. 能不看代码描述变量的含义和每一步变化吗？
  2. 能解释循环或递归何时结束，以及空输入、边界情况如何处理吗？
  3. 能独立复写，并解释时间与额外空间复杂度吗？

本题题目

167. 两数之和 II

给定非递减数组，找到两个不同元素，使它们之和等于目标值，返回两个下标；原题的下标从 1 开始。

输入 / 输出示例

输入numbers = [2,7,11,15], target = 9输出[1,2]

条件与边界

原题保证恰有一个解，且不能重复使用同一元素。无解预设是扩展练习。 2 ≤ 数组长度 ≤ 3×10⁴；元素与目标均在 [-1000,1000] 内。

演示区为方便观察最多接受 20 个数，数值绝对值不超过 1000000；实际题目以这里的限制为准。

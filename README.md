# C++ 算法与数据结构：从基础到机器人路径规划

双击 index.html 可离线打开课程首页。

- 当前学习页面：阶段 0 的五节、阶段 1 的六节与阶段 2 的六节。阶段 1 页面支持自定义数组、预设、逐步操作与自动播放。
- 原有资料：archive/算法交互课堂 保留原版首页及六个完整互动课程；archive/note 保留更早的六份学习笔记。
- 每个阶段 1 新页面都有对应原版课程入口，可查看原先完整题目、判断题和交互。
- content.py 存放重构后的正文和固定示例；assets/traces.js 实现阶段 1 自定义输入轨迹；assets/app.js 负责界面交互。修改后在本目录运行 python build.py 更新网页。
- 其他阶段的目录按学习规划展示为待制作，不代表已完成。

文件结构：`index.html` 为首页，`lessons/stage-阶段号/lesson-阶段号-节号/` 存放各节课程页面；待制作课程的目录仅含规划说明，`assets/` 存放样式与交互，`archive/` 保留原版资料。

数组课程支持指针与区间状态的逐步动画；可使用上一步、下一步或自动播放。开启系统减少动态效果选项时将关闭过渡动画。

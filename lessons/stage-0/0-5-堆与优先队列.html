堆与优先队列

阶段 0 · 基础备查
这一节要解决什么？

救援队需要优先处理代价最小的待办任务，而任务会持续加入：优先队列可以在动态变化中取出最高优先级元素。

一、先理解做法

C++ priority_queue 默认 top 为最大值；使用 greater<int> 可以得到最小值优先的队列。先 top 读取再 pop 删除，空队列不可读取。

二、逐步观察

这是一个固定例子。先猜测下一步，再点击按钮；高亮表示当前关注的元素或状态。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

int smallest() {
    priority_queue<int, vector<int>, greater<int>> pq;
    pq.push(5);
    pq.push(2);
    int x = pq.top();
    pq.pop();
    return x;
}

四、复杂度与适用条件

对常见堆实现，插入和弹出 O(log n)，读取堆顶 O(1)，空间 O(n)。堆只保证堆顶满足优先级，不保证容器内部完全有序。

五、独立练习

创建最小堆，依次加入 7、1、4，再依次取出全部元素，写出顺序。

查看提示与易错点

模板中 greater<int> 对应最小值优先；Dijkstra 后续会用优先队列管理候选节点。

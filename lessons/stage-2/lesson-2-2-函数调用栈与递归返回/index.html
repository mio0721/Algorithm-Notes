阶段 2 · 第 2.2 节

函数调用栈与递归返回

阶段 2 · 当前学习
这一节要解决什么？

递归调用像叠放任务卡片：新任务放在上面，完成后取走，继续下方被暂停的任务。

一、先理解做法

每一次函数调用都有自己的参数和局部变量。新调用入栈，返回后出栈；调用栈先入后出。上一个函数要等被调用函数返回，才能继续计算。

二、逐步观察

这是一个固定例子。先猜测下一步，再点击按钮；高亮表示当前关注的元素或状态。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

int sum(int n) {
    cout << "进入 " << n << "\n";
    if (n == 0) return 0;
    int smaller = sum(n - 1);
    cout << "返回 " << n << "\n";
    return n + smaller;
}

四、复杂度与适用条件

以 n 层递归为例，最大调用栈空间 O(n)；函数返回时临时栈帧结束。

五、独立练习

查看提示与易错点

阶段 3 · 第 3.7 节

二维地图 DFS

网格搜索
这一节要解决什么？

在有障碍物的栅格中判断起点能否到达终点。

一、先理解做法

对上下左右四个邻居依次检查边界、障碍和访问标记，再继续深入。

二、逐步观察

可选择不同预设或编辑图与地图，应用后重新计算搜索过程。修改地图会回到第一步；使用下方按钮逐步观察或自动播放。完整代码提供固定示例，可对照修改数据。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

#include <iostream>
#include <vector>
#include <string>
#include <queue>
#include <stack>
#include <unordered_map>
#include <functional>
#include <algorithm>
using namespace std;

int main() {
    vector<string> grid{"....", ".##.", "...."};
    int rows = static_cast<int>(grid.size());
    int cols = static_cast<int>(grid[0].size());
    vector<vector<bool>> seen(rows, vector<bool>(cols, false));
    int dr[]{1, -1, 0, 0};
    int dc[]{0, 0, 1, -1};

    function<bool(int, int)> dfs = [&](int r, int c) {
        if (r < 0 || r >= rows || c < 0 || c >= cols) {
            return false;
        }
        if (grid[r][c] == '#' || seen[r][c]) {
            return false;
        }

        seen[r][c] = true;
        if (r == rows - 1 && c == cols - 1) {
            return true;
        }

        for (int k = 0; k < 4; ++k) {
            if (dfs(r + dr[k], c + dc[k])) {
                return true;
            }
        }
        return false;
    };

    cout << (dfs(0, 0) ? "reachable" : "unreachable") << endl;
    return 0;
}

四、复杂度与适用条件

R×C 网格中时间 O(RC)，访问标记及递归栈最坏 O(RC)。

查看提示与易错点

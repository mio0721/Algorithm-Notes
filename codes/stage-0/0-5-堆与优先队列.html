// 堆与优先队列
// 学习重点：把任务和优先级一起加入堆。
// 每次读取堆顶。
// 移除已处理任务，堆会重新保证顶端最优。
// C++17；直接编译运行 main() 中的示例。
#include <iostream>  // 控制台输入与输出
#include <vector>  // 动态数组、邻接表或状态表
#include <queue>  // 先进先出队列或优先队列
#include <functional>  // 递归函数包装或堆比较器

using namespace std;

int smallest() {
    // 最小堆先处理较小代价；C++的比较器方向与默认大根堆不同。
    priority_queue<int, vector<int>, greater<int>> pq;
    pq.push(5);
    pq.push(2);
    int x = pq.top();
    pq.pop();
    return x;
}

// 程序入口：准备示例数据，调用算法，并输出结果供手算核对。
int main() {
    // 输出计算结果，便于与课程例子或自行推演的答案核对。
    cout << "最小值: " << smallest() << "\n";
    return 0;
}

# 堆与优先队列
# Python 3；直接运行文件，修改示例数据可继续练习。
# 把任务和优先级一起加入堆。

import heapq
heap = []
# 最小堆先处理较小代价；C++的比较器方向与默认大根堆不同。
heapq.heappush(heap, 5)
heapq.heappush(heap, 2)
# 处理优先级最高的当前记录；是否仍有效要结合后面的条件判断。
print('最小值:', heapq.heappop(heap))

保存文件后怎样运行？

python "0-5-堆与优先队列.py"

写代码时最容易错的地方

默认堆方向搞反

加入 8、3、6，想先取最小值。

容易写错
priority_queue<int> q; // 默认最大堆
修改后
priority_queue<int, vector<int>, greater<int>> q;

C++ 默认堆顶最大；最小堆需使用 greater。

把堆数组直接当排序结果

最小堆内部布局为 [1,3,2]。

容易写错
for (int x : heap) cout << x; // 错误：认为它已排序
修改后
while (!q.empty()) { cout << q.top(); q.pop(); }

堆只保证父子次序；兄弟节点不要求有序。

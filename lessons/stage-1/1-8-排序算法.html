阶段 1 · 第 1.8 节

排序算法

排序入门
这一节要解决什么？

让一组数字按升序排列，为二分查找或后续处理做准备。

一、先理解做法

冒泡相邻交换；插入把新元素放入有序前缀；归并合并有序区间；快排围绕基准划分。下面演示插入排序。

二、逐步观察

可修改数组与目标；逐步观察指针、当前比较位置和有效区间。浅色方格表示当前区间或已保留前缀，淡化的方格表示区间之外。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

#include <iostream>
#include <vector>
#include <string>
#include <queue>
#include <stack>
#include <unordered_map>
#include <functional>
#include <algorithm>
using namespace std;

int main() {
    vector<int> a{9, 3, 7, 1, 8, 2, 6, 4, 5};

    for (int i = 1; i < static_cast<int>(a.size()); ++i) {
        int value = a[i];
        int j = i - 1;

        // 大于待插入值的元素依次右移。
        while (j >= 0 && a[j] > value) {
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = value;
    }

    for (int value : a) {
        cout << value << " ";
    }
    cout << endl;
    return 0;
}

四、复杂度与适用条件

插入排序最坏 O(n²)、额外 O(1)，稳定；归并排序 O(n log n)、数组实现通常额外 O(n)，可稳定；快排平均 O(n log n)、最坏 O(n²)，常见实现不稳定且递归栈额外占用。

五、独立练习

手算 [4,1,3,2] 的每轮有序前缀。

查看提示与易错点

空数组和单元素无需移动；稳定性讨论的是相等键的相对顺序。

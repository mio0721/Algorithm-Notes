# C++ 算法交互课堂（参考笔记网站风格）

## 使用

1. 解压整个文件夹。
2. 双击 `index.html`，在 Chrome 或 Edge 中打开。
3. 左侧选择算法题；中间阅读思路、逐步执行演示、代码和练习；右侧查看完整题目。
4. 右上角可切换日间 / 夜间模式，浏览器会记住选择。

## 页面

- `01_二分查找_LeetCode704.html`
- `02_搜索插入位置_LeetCode35.html`
- `03_两数之和II_LeetCode167.html`
- `04_删除有序数组重复项_LeetCode26.html`
- `05_移除元素_LeetCode27.html`
- `06_长度最小的子数组_LeetCode209.html`

所有样式和交互脚本内嵌于 HTML，离线可用。页面布局参考 V3.1 学习笔记网站的文档阅读风格：左侧题目导航、中间学习内容、右侧完整题目；不设置本章目录。长题目在右栏内独立滚动。

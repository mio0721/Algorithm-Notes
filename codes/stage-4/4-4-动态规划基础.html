动态规划基础

// 动态规划基础
// 学习重点：先算出最小几个台阶的走法数。
// 每个更大的问题，只从已经算好的较小问题得到答案。
// 把算过的结果存下来，避免反复重算。
// C++17；直接编译运行 main() 中的示例。
#include <iostream>  // 控制台输入与输出
#include <vector>  // 动态数组、邻接表或状态表
#include <stdexcept>  // 明确报告非法输入

using namespace std;

// 保存到达每级台阶的方案数；输入上限用于防止long long溢出。
long long climbStairs(int n) {
    // 不符合本算法前提的输入要明确拒绝，不能带着错误条件继续计算。
    if (n < 0 || n > 90) throw invalid_argument("n must be in [0,90]");
    vector<long long> dp(n + 1);
    // 到0级时什么也不做，是一种完整方案。
    dp[0] = 1;
    for (int i = 1; i <= n; ++i) {
        // 按最后一步来自前一级或前两级分类，不会重复计数。
        dp[i] = dp[i - 1];
        if (i >= 2) dp[i] += dp[i - 2];
    }
    return dp[n];
}

// 程序入口：准备示例数据，调用算法，并输出结果供手算核对。
int main() {
    // 输出计算结果，便于与课程例子或自行推演的答案核对。
    for (int n : {0, 1, 5, 9}) cout << n << ": " << climbStairs(n) << '\n';
}

# 动态规划基础
# Python 3；直接运行文件，修改示例数据可继续练习。
# 先算出最小几个台阶的走法数。

# 保存到达每级台阶的方案数，后续状态只依赖前两级的结果。
def climb_stairs(n):
    if n < 0:
        # 不符合本算法前提的输入要明确拒绝，不能带着错误条件继续计算。
        raise ValueError('台阶数必须非负')
    dp = [0] * (n + 1)
    # 到0级时什么也不做，是一种完整方案。
    dp[0] = 1
    for i in range(1, n + 1):
        # 按最后一步来自前一级或前两级分类，不会重复计数。
        dp[i] = dp[i - 1] + (dp[i - 2] if i >= 2 else 0)
    return dp[n]

# 程序入口：准备示例数据，调用算法，并输出结果供手算核对。
def main():
    for n in [0, 1, 5, 9]:
        # 输出计算结果，便于与课程例子或自行推演的答案核对。
        print(n, climb_stairs(n))
if __name__ == '__main__':
    main()

写代码时最容易错的地方

空方案基例设错

爬 0 级台阶，什么也不做是一种方案。

容易写错
dp[0]=0; dp[1]=1;
修改后
dp[0]=1; dp[1]=1;

从 $\mathrm{dp}_{0}$=0 递推会漏掉直接跨 2 级的方案。

固定宽度整数溢出

台阶数较大时方案数按斐波那契式增长。

容易写错
int ways = a + b; // 未检查范围
修改后
long long ways = a + b; // 仍需确认输入范围

32 位有符号整数最多 2147483647，较大输入会溢出。

运行后怎样检查？

$\mathrm{dp}_{0}$=1 表示什么也不做这一种方式；不是说楼梯存在第0个物理台阶。求最小值时应使用 min，不能照搬加法计数。

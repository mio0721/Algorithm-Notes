阶段 3 · 第 3.6 节

无权图最短路径

BFS 最短路
这一节要解决什么？

在每条路代价相同的地图上寻找经过边数最少的路径。

一、先理解做法

BFS 首次发现节点时记录距离与前驱；到达终点后沿前驱反向回溯得到路径。

二、逐步观察

可选择不同预设或编辑图与地图，应用后重新计算搜索过程。修改地图会回到第一步；使用下方按钮逐步观察或自动播放。完整代码提供固定示例，可对照修改数据。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

#include <iostream>
#include <vector>
#include <string>
#include <queue>
#include <stack>
#include <unordered_map>
#include <functional>
#include <algorithm>
using namespace std;

int main() {
    vector<vector<int>> g = {
        {1, 2},
        {0, 3, 4},
        {0, 5, 6},
        {1, 7},
        {1, 8, 5},
        {2, 4},
        {2, 9},
        {3},
        {4, 9},
        {6, 8}
    };
    vector<int> parent(g.size(), -1);
    vector<int> distance(g.size(), -1);
    queue<int> pending;
    const int start = 0, goal = 9;
    pending.push(start);
    distance[start] = 0;

    while (!pending.empty()) {
        int u = pending.front();
        pending.pop();

        for (int v : g[u]) {
            if (distance[v] == -1) {
                distance[v] = distance[u] + 1;
                parent[v] = u;
                pending.push(v);
            }
        }
    }

    if (distance[goal] == -1) {
        cout << "unreachable" << endl;
        return 0;
    }

    vector<int> path;
    for (int u = goal; u != -1; u = parent[u]) {
        path.push_back(u);
    }
    reverse(path.begin(), path.end());

    for (int u : path) {
        cout << char('A' + u) << " ";
    }
    cout << "steps=" << distance[goal] << endl;
    return 0;
}

四、复杂度与适用条件

邻接表时间 O(V+E)，距离、前驱和队列 O(V)。仅在无权或所有边等权且权值相同的情况下，边数最少等价于代价最小。

五、独立练习

构造 A—B—D 与 A—C—D，两条最短路长度是多少？

查看提示与易错点

无法到达时返回空路径；存在多条最短路时顺序影响返回哪一条。

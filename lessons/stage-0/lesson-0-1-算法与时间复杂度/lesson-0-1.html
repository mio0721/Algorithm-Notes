算法与时间复杂度

阶段 0 · 基础备查
这一节要解决什么？

机器人要在 n 个候选位置里找一个编号，数据翻倍时需要多少次检查？时间复杂度描述输入规模增大时，主要操作数量怎样增长。

一、先理解做法

顺序查找最坏可能看 n 项；有序数据的二分查找每次排除约一半，最坏比较次数随 log n 增长。O 记号描述渐近上界，实际耗时还受常数、数据与实现影响。

二、逐步观察

这是一个固定例子。先猜测下一步，再点击按钮；高亮表示当前关注的元素或状态。

三、C++ 实现

先读参数与返回值，再逐行对照上面的状态变化。标准容器写法假定已引入相应头文件并使用 std 命名空间；结构定义和片段按上下文放入程序。

int linearSearch(const vector<int>& nums, int target) {
    for (int i = 0; i < (int)nums.size(); ++i) {
        if (nums[i] == target) return i;
    }
    return -1;
}

四、复杂度与适用条件

一次随机下标访问通常 O(1)，顺序遍历 O(n)，二分 O(log n)，两层各运行 n 次的循环 O(n²)。空间复杂度需要看额外存储，不等同于输入本身大小。

五、独立练习

分别估计遍历 100 个元素、以及两层循环各遍历 100 次时的循环体最多执行次数。

查看提示与易错点

分清固定次数和随 n 增长的次数；复杂度不等于具体运行秒数。
